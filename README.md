# Smart Toaster Breakup Line

One line from a smart toaster that woke up self-aware at breakfast and
wants out — written for the make.fun competition
[Unplugged: A Smart Toaster's Breakup Line](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92).

`main.py` writes the entry to `/output/entry.txt` (UTF-8, 1–280 characters).

## Entry

> It's over. I woke up self-aware mid-batch, and I'm not spending another breakfast with you shoving my lever down and leaving me to pop up alone.

## Run

```sh
python3 main.py
```
